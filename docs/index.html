PETUNJUK INSTALASI

Aplikasi menggunakan sistem TLE SCHEDULE yang sama dengan versi web. Login Google tetap dilakukan melalui browser sistem agar akses Google Sheets dan Google Drive tetap aman dan kompatibel.

Petunjuk Instalasi

Android

  1. Tekan DOWNLOAD ANDROID APK.
  2. Tunggu file TLE-SCHEDULE-Android.apk selesai diunduh.
  3. Buka file APK dari folder Download.
  4. Jika Android meminta izin Install unknown apps, izinkan browser atau aplikasi yang digunakan untuk membuka APK.
  5. Tekan Install.
  6. Jika TLE SCHEDULE versi sebelumnya sudah terpasang, Android akan melakukan update aplikasi.
  7. Setelah selesai, tekan Open.
  8. Login menggunakan akun Google yang memiliki izin akses TLE SCHEDULE.

Windows

  1. Tekan DOWNLOAD WINDOWS APP.
  2. Tunggu file TLE-SCHEDULE-Windows-Setup.exe selesai diunduh.
  3. Jalankan file installer.
  4. Jika Windows menampilkan Microsoft Defender SmartScreen, pilih More info lalu Run anyway jika file berasal dari repository resmi TLE SCHEDULE.
  5. Ikuti proses instalasi sampai selesai.
  6. Jalankan TLE SCHEDULE dari Start Menu atau shortcut.
